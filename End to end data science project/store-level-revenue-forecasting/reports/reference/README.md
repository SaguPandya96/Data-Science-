# Reference results

These tables record the verified full-data run used in the project README. They were produced from 1,017,209 Rossmann daily observations with the final six weeks held out under the rolling one-day-ahead forecast contract.

They are checked in so a portfolio reader can inspect the measured result without downloading the source data or retraining the model. Normal reruns write fresh artifacts to `reports/metrics/`, `reports/tables/`, and `reports/figures/`.
