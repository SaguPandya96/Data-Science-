# Data Science

This repository collects my data science study material and end-to-end projects.

## End-to-end projects

- [Amazon Review Intelligence and Recommender System](End%20to%20end%20data%20science%20project/Amazon%20Review%20Intelligence%20and%20Recommender%20System/)
  - Recommenders, sentiment NLP and SHAP-explained rating inference on 700k Amazon reviews. Matrix factorization lost to a popularity baseline, and the baseline's own advantage then turned out to be mostly an artifact of how negatives were sampled. Served through a FastAPI layer and a Streamlit demo, with tests and CI.

- [SupplyLens: Supplier Delivery Risk and Operational Decision Intelligence](End%20to%20end%20data%20science%20project/SupplyLens/)
  - A reproducible shipment-risk project covering public-data validation, temporal modeling, calibrated probabilities, review-capacity analysis, supplier scorecards, testing, and monitoring.

- [GitHub Open-Source Repository Recommendation System](End%20to%20end%20data%20science%20project/GitHub%20Open-Source%20Repository%20Recommendation%20System/)
  - Can a developer's public GitHub history surface relevant repositories that popularity alone would miss? Chronological evaluation, seen-item filtering, model comparisons and explainable rankings over real public data.

- [Crypto Alternative Data Forecasting](End%20to%20end%20data%20science%20project/crypto-alternative-data-forecasting/)
  - Does Bitcoin-news sentiment improve a next-day direction model built from market data? Benchmarked against a market-data-only baseline rather than reported in isolation.
